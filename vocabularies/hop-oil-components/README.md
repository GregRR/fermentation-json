# FermentationJSON hop-oil-component vocabulary

This vocabulary identifies hop essential-oil components whose native representation is a fraction of total hop essential oil.

The initial terms are intentionally narrower than BeerJSON `OilContentType`: BeerJSON groups cohumulone, polyphenols, and xanthohumol in the same object even though established hop-analysis methods treat those as analytically distinct from essential-oil composition. Ambiguous BeerJSON `pinene` is also not assigned a more specific native chemical identity.

Extensions use absolute URI identifiers.
