# Measurement scales vocabulary

This directory contains FermentationJSON identifiers for numerical measurement
scales and analytical indices whose semantics are not adequately represented by
a physical unit alone.

A measurement scale is **not a unit alias**. Conversions between scale-defined
quantities require an explicit model, table, analytical method, or reference
condition as specified by the applicable scale definition.

Core scale identifiers use lower snake case. Extension scale identifiers use
absolute URIs under the general vocabulary-extension policy.
